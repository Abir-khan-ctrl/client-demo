# Marvella's Cafe & Lounge website

Open `index.html` in any browser to view the site. It is a complete static website, so it can be uploaded to Netlify, GitHub Pages, Hostinger, or any normal web host without a build step.

## Easy edits

- Change text directly in `index.html`.
- Replace or add photos in `assets/images/`, then update the matching image path in `index.html`.
- Change colours and spacing from the variables at the top of `styles.css`.
- Confirm the cafe's email address in `script.js` before publishing; it is the only contact detail not provided in the brief.

All key live links are already connected: Google Maps, Google Reviews, Instagram, WhatsApp, direct calling, online menu, and table booking.
